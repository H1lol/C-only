# Release readiness

The native 23–30 release check validates source-level recovery/performance/license gates. Android packaging is scaffolded but requires a Flutter SDK, Android SDK, NDK and a real device/emulator for final verification.

A production studio should complete: device matrix testing, long-session stress tests, codec/licensing review, crash telemetry policy, GPU backend validation, plugin sandboxing, security review, and final third-party license audit.
