# Open source policy

- **MotionStudio app**: fully open source.
- **`.msp` plugins**: authors are **recommended** to release source under an OSI license (MIT, Apache-2.0, GPL-3.0, etc.).
- Official / featured store plugins should set `"open_source": true` and provide `source_url` + `LICENSE` inside the `.msp`.
- The Effect Store UI can badge and prefer open plugins.
