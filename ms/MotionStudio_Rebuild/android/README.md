# Motion Studio — Android app (Kotlin + C++)

The Android application is a single Kotlin/Compose module that drives the C++
engine in `../native/cpp` over JNI. There is no Flutter, no Dart and no widget
layer between the UI and the renderer.

```
android/
├── settings.gradle.kts          project + :app
├── build.gradle.kts             AGP 8.7.2, Kotlin 2.0.21
└── app/
    ├── build.gradle.kts         Compose, NDK/CMake wiring, SDK 35 / min 29
    └── src/
        ├── main/
        │   ├── cpp/
        │   │   ├── CMakeLists.txt      builds native/cpp + the JNI library
        │   │   └── ms_jni_bridge.cpp   JNI over the C ABI
        │   └── kotlin/com/motionstudio/app/
        │       ├── MainActivity.kt      ComponentActivity + Compose
        │       ├── native/NativeEngine.kt
        │       ├── editor/EditorEngine.kt
        │       ├── audio/NativeAudioPlayer.kt   AudioTrack <- engine PCM
        │       ├── data/ProjectStore.kt, SettingsStore.kt
        │       ├── model/ProjectDoc.kt
        │       └── ui/ StarterScreen, EditorScreen, TimelinePane,
        │              PreviewView, SettingsScreen, MoreSheet, theme/
        └── test/kotlin/...           JVM tests for the native JSON contract
```

## Ownership rules

- **C++ owns the document.** The project (`.msproj` JSON), timeline edits, undo,
  compositing, audio mix and master chain live in the engine. Kotlin re-parses
  the JSON for drawing only and never writes its own schema.
- **Kotlin owns the device.** Lifecycle, Storage Access Framework imports,
  `AudioTrack` output, file storage, preferences.
- **One bridge.** Every engine call goes through `NativeEngine` (JNI) →
  `native/cpp/bridge/ms_bridge.h`.

## Build

```bash
export JAVA_HOME=/path/to/jdk17
export ANDROID_HOME=/path/to/android-sdk
cd android
gradle :app:assembleDebug        # APK at app/build/outputs/apk/debug/
gradle :app:testDebugUnitTest    # JVM tests
```

`local.properties` must contain `sdk.dir` for your machine (git-ignored).

Requirements: JDK 17, Android SDK 35, NDK 27.0.12077973, CMake 3.22.1.
The engine is compiled by CMake from `../native/cpp` with `MS_BUILD_TESTS=OFF`
so the desktop test binaries are not built for Android.

## Bundled third-party assets

- `res/font/inter_*.ttf`, `res/font/jbmono_*.ttf` — Inter 4.1 and JetBrains Mono
  2.304, both SIL OFL 1.1. See `../third_party/fonts/README.md`.
- `assets/looks/*.cube` — six 17³ looks generated by `../scripts/gen_looks.py`
  (project-authored, GPL-3.0-or-later). The C++ engine loads them through
  `ms_look_load` and applies them to the preview after the frame cache.
